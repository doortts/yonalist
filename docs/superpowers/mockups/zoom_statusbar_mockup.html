Yonalist Zoom Status Bar Indicator - 디자인 시안

현재 페이지 Zoom 레벨이 100%가 아닐 때 하단 상태바(Status bar) 표시 방식 시안입니다.

🔍 Zoom 레벨 테스트:
선택 항목:
Yonalist
• 버그 리포트 (현재 Zoom: 100%)
우측 상단 메뉴 버그 수정 완료
인스턴트 툴팁 0ms 표시 적용
하단 상태바 줌 레벨 표시 기능 검토 중
Cmd+= / Cmd+- 로 줌 인/아웃 가능
3 selected Online
💡 안내: 상단의 Zoom 레벨 테스트 버튼(80%, 110% 등)을 누르면 상태바에 해당 시안의 줌 인디케이터가 실시간으로 나타납니다. 100%일 때는 상태바가 깨끗하게 유지되도록 자동으로 숨겨집니다.
