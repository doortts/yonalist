일어난 일

자동 규칙은 상태가 아니라 전이에 붙는다

선언 모델에서 “완료된 부모 + 열린 자식”은 정상 상태다. 그래서 규칙이 그 상태를 보고 움직이면 선언을 즉시 되돌려 버린다. 무언가 바뀌는 순간에만 움직인다.

전이자동으로 하는 일근거
행이 완료로 바뀜부모의 직계 자식이 이제 전부 완료면 부모도 완료, 위로 계속마지막 자식을 끝냈으면 부모도 끝난 것
완료였던 행이 열림부모의 완료를 해제, 위로 계속다시 열린 일이 있는데 부모가 끝났다고 할 수 없다
내용 있는 행이 새로 놓임위의 완료된 행들을 해제새로 도착한 일은 선언을 무효로 한다
완료 안 된 행이 떠남남은 직계 자식이 전부 완료면 부모 완료마지막 걸림돌이 사라졌다
손으로 열린 채 남긴 자식아무 것도 하지 않는다전이가 아니다. 못 하게 된 일은 열린 채로 남는다
내용 있는 행의 텍스트 수정아무 것도 하지 않는다빈 행 → 내용만 전이다. 버려둔 행의 오타를 고쳐도 부모는 닫힌 채
선언 모델에서는 조상 판정이 직계 자식만 읽는다. 그래서 명령이 읽는 창이 페이지 전체에서 조상 경로 + 각 조상의 직계 자식으로 줄고, 5천 행 83ms · 5만 행 985ms로 측정된 완료 토글이 페이지 크기와 무관해진다.
