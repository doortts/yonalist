# Notes 블릿 광학 정렬 설계

## 목표

일반 블릿을 제목의 28px 라인박스 중앙에 안정적으로 맞춘다.

## 완료 조건

- 블릿 점에 별도의 수직 이동 transform을 적용하지 않는다.
- 접힘·호버·키보드 포커스 시 나타나는 원형 상태 표시도 같은 중앙을 유지한다.
- 28px 행 높이, 제목 line-height, 그리드 열, 클릭 영역은 바뀌지 않는다.

## 설계

`.notes-node-bullet` 버튼과 시각 요소인 `::before`, `.notes-node-bullet-dot`은
기존 flex 중앙 정렬을 그대로 사용한다. 글자 획의 외곽 상자는 문자열과 폰트에 따라
중심이 달라지므로 이를 기준으로 고정 보정하지 않는다. 새 스크린샷에서 `-3px`
보정은 블릿을 글자 획 중심보다 5~7 화면 픽셀 위로 이동시켰고, 보정을 제거하면
행별 오차가 약 ±1 화면 픽셀로 줄어든다.

## 비대상

- 블릿 크기와 색상 변경
- 접기 화살표, 메뉴 버튼, 가이드 라인의 위치 변경
- 페이지 제목이나 설명 노트의 타이포그래피 변경

## 검증

기존 CSS 계약 테스트에 블릿 점과 상태 표시가 수직 transform을 사용하지 않는다는
계약을 추가한다.
집중 테스트와 프런트엔드 최종 검증을 실행한다.
